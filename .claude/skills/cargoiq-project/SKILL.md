# CargoIQ project

Mission:
Evidence -> Timeline -> Contradiction -> Rule -> Money -> Human review -> Evidence pack.

Always:
- Inspect before editing.
- Preserve useful existing work.
- Keep tenant boundaries explicit.
- Preserve source/provenance.
- Keep financial calculations deterministic.
- Label demo, planned, inferred, disputed and unknown states.
- Respect external-source terms.
- Report what was actually verified.

Never:
- invent facts;
- invent money;
- present mock data as live;
- call an inference verified;
- expose provider secrets;
- delete ambiguous code without an audit;
- automate consequential external actions without approval.
