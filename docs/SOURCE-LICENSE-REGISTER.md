# CargoIQ Source / Licence Register

This register is intentionally conservative. Technical accessibility is not treated as commercial redistribution permission.

| Source family | CargoIQ use | Status |
|---|---|---|
| Copernicus Sentinel-1/2 | satellite corroboration | APPROVED_FOR_REVIEW |
| OpenStreetMap | geography / geofences | APPROVED_WITH_ODBL |
| AISStream | live AIS ingestion | REVIEW_BEFORE_COMMERCIAL_PRODUCTION |
| Global Fishing Watch | research / vessel corroboration | NON_COMMERCIAL_UNTIL_LICENSED |
| Public municipal/transport CCTV | contextual visual corroboration | PROVIDER_BY_PROVIDER |
| Google/3D basemaps | visual globe where terms permit | PROVIDER_TERMS |
| Commercial maritime providers | enhanced vessel/history data | CONTRACT_REQUIRED |

For each provider retain:
- official URL
- licence/terms
- commercial-use status
- attribution
- retention rights
- redistribution rights
- customer-display rights
- derived-data rules
- review date

Never promote a source to production-commercial status solely because an API is publicly reachable.
