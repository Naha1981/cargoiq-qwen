# Public corroboration

Use:
- AIS
- Copernicus Sentinel
- weather
- OSM
- official port/terminal notices
- lawful public CCTV
- public aviation/maritime registries where permitted
- reputable public event sources

Normalize every observation before linking it to a case.

Persist:
- provider
- official URL
- retrieval time
- observed time
- licence status
- attribution
- geographic relevance
- limitations

Classify observations:
SUPPORTS / CHALLENGES / CONTEXT_ONLY / INSUFFICIENT / NOT_MATCHED.

Commercial-use permission must be verified separately from technical API availability.
